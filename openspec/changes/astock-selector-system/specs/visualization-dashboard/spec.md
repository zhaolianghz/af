## ADDED Requirements

### Requirement: 大屏布局

系统 MUST 提供独立路由 `/dashboard` 的可视化大屏，1920×1080 适配，模块化分区。

#### Scenario: 打开大屏
- **WHEN** 用户访问 `/dashboard`
- **THEN** 系统返回大屏页面，按"持仓 / 今日推荐 / 方案胜率排行 / T+1 胜率热力图 / 复盘入口"分区展示，首屏延迟 < 2s

### Requirement: 当前持仓

系统 MUST 在大屏展示"当前持仓股"卡片列表，含股票代码 / 名称 / 持仓成本 / 现价 / 浮动盈亏 / 持仓天数。

#### Scenario: 持仓数据刷新
- **WHEN** 实时行情推送股票 600519 价格变更
- **THEN** 大屏上 600519 卡片"现价"与"浮动盈亏"在 5 秒内更新

### Requirement: 今日推荐与方案排行

系统 MUST 在大屏展示"今日新增推荐"列表与"方案胜率排行"TOP 10。

#### Scenario: 查看方案排行
- **WHEN** 用户在大屏查看方案排行
- **THEN** 系统按近 30 日累计胜率倒序展示方案卡片，点击进入方案详情

### Requirement: T+1 胜率热力图

系统 MUST 展示按"方案 × 时段标签"二维的热力图，颜色深浅表示 T+1 胜率高低。

#### Scenario: 切换热力图维度
- **WHEN** 用户把热力图维度从 T+1 切换到 T+3
- **THEN** 系统重新拉取 T+3 胜率数据并刷新图表

### Requirement: 复盘入口

系统 MUST 在大屏提供"进入复盘"入口，跳转到按日期 / 方案 / 股票筛选的复盘详情页。

#### Scenario: 进入复盘
- **WHEN** 用户点击"复盘"按钮
- **THEN** 系统跳转到 `/review?date=...` 复盘页，可按方案 / 标签 / 行业筛选当日所有推荐
