## Why

散户和量化爱好者难以在 A 股市场把"选股思路"快速验证、迭代、并系统化地落地：现有平台要么门槛高（需要写代码、搭工程），要么黑盒（看不懂为何选了这只票），要么只能跑一次、无法并行对比多套思路。本系统要把"选股逻辑"变成可拖拽、可复用、可调度、可回测的可视化工作流，让用户既能手工点一下看今天推什么票，也能挂定时任务让系统在早盘/午盘/尾盘自动跑，并把每一次推荐的可视化结果沉淀下来做胜率复盘。

## What Changes

- **新增选股编排画布（dify/n8n 风格）**：节点化的拖拽编辑器，支持数据源节点（实时行情、K 线、龙虎榜、财务、新闻）、技术指标节点（MA/MACD/KDJ/布林/自定义公式）、筛选节点（量价、形态、行业）、打分排序节点、过滤去重节点；节点之间用有向边连接形成 DAG。
- **新增"荐股方案/策略"管理**：方案支持编码 + 名称 + 版本 + 标签 + 描述；多条方案可并存、并行执行、相互独立；支持启用/停用、克隆复制、导入导出 JSON。
- **新增执行触发器**：每个方案可挂 Cron 表达式（支持 A 股交易日历感知，例如"每个交易日 09:25/10:30/14:30"）+ 手工"立即执行"按钮；执行过程展示实时日志与节点级耗时。
- **新增推荐结果落库**：每次执行产出推荐表，记录 `日期 / 股票名称 / 股票代码 / 加入区间(起止价) / 荐股方案编码 / 荐股方案名称 / 节点链路快照 / 标签 / 生成时间`。
- **新增"时段标签"（多选）**：每条推荐可被打上 早盘 / 尾盘 / 无后盘 / 复盘 中的**一个或多个**标签，由编排流程中"时段"节点根据执行时刻或用户显式指定判定；同一只股票在同一天被不同时段推荐时，标签会**叠加**保留在历史记录中。
- **新增行情数据源适配层**：统一接口对接实时五档/K线/财务数据（默认实现走东方财富/新浪公开接口，可替换为 Tushare/AKShare/自建行情网关）。
- **新增绩效与胜率引擎**：跟踪每条推荐自推荐日以来的最高/最低/收盘价，计算 累计胜率、T+1 胜率、T+3 胜率、T+5 胜率、最大回撤、平均持有收益；按方案/标签/行业/股票维度聚合。
- **新增可视化大屏**：浏览器全屏看板，展示 当前持仓、今日新增推荐、方案胜率排行、T+1/T+3/T+5 胜率热力图、最近 N 日推荐分布、复盘入口。
- **新增用户体系与权限**：基础账户登录、方案访问隔离、只读/编辑/管理员三种角色（多用户协作时启用）。

## Capabilities

### New Capabilities

- `selection-orchestration`: 低代码选股编排画布（节点 + DAG + 实时调试 + 节点复用）。
- `strategy-management`: 荐股方案/策略的 CRUD、版本、克隆、导入导出。
- `execution-engine`: 定时调度（交易日历感知）+ 手工触发 + 执行历史 + 实时日志。
- `market-data`: 行情数据源适配层（实时行情、K线、财务、新闻、统一接口）。
- `recommendation`: 推荐结果落库与查询（含日期/股票/加入区间/方案/标签等字段）。
- `session-tagging`: 时段标签体系（早盘/尾盘/无后盘/复盘），**多对多**，同一股票同日可携带多个标签，用于分组与统计。
- `ai-assistant`: AI 对话式方案管理 —— 通过自然语言对话完成"创建 / 编辑 / 复制 / 删除 / 导入"选股方案，并把对话翻译为编排画布上的 DAG（节点增删 + 边改写 + 参数更新），支持预览 → 用户确认 → 落库的两阶段流程。
- `performance-analytics`: 胜率与绩效计算引擎（T+1/T+3/T+5、累计胜率、回撤、收益）。
- `visualization-dashboard`: 可视化大屏（持仓、推荐、胜率、方案排行、复盘入口）。
- `user-auth`: 账号、登录、方案访问隔离与角色权限（仅多用户时启用，单机版可弱化）。

### Modified Capabilities

无（项目初始，无既有 spec）。

## Impact

- **新增仓库代码**：后端建议 Go（Gin + GORM + 内嵌调度器）或 Python（FastAPI + APScheduler + Celery）；前端 React + TypeScript + ReactFlow（编排画布）+ ECharts/AntV（图表）+ Vite + Electron（可选桌面端）。
- **新增数据源依赖**：行情接口（东方财富/新浪/Tushare/AKShare 任选其一为默认，可替换）。
- **新增基础设施**：关系型数据库（MySQL/PostgreSQL 任一）存储方案、节点定义、执行历史、推荐结果、绩效快照；时序缓存（Redis）存实时行情与当日推荐；可选 ClickHouse 存历史 K 线。
- **影响面**：全新项目，无既有代码改动。
- **非目标（v1 不做）**：实盘交易接入、券商下单、组合再平衡、跨市场（港美股）适配、AI 选股大模型集成。
